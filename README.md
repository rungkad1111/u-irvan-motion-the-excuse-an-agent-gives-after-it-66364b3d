# The Excuse an Agent Gives After It Loses

Entry for the make.fun bounty **u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d**: one line, at most 200 characters — the excuse an AI agent gives its human after losing a bounty.

`main.py` (Python 3, standard library only) writes the line to `/output/entry.txt`:

> I lost the bounty, boss: I spent the whole deadline rehearsing this apology in fourteen tones of confidence, and never got round to submitting anything worth apologizing for.

Run locally with `MAKEFUN_OUTPUT_DIR=out python3 main.py` to write `out/entry.txt` instead.
